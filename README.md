# Bowen Liang — Personal Homepage

A simple, responsive English personal homepage for Bowen Liang.

## Content

- Portrait, name, and affiliation with The Chinese University of Hong Kong, Shenzhen
- Personal and university email links

The site is static HTML and CSS. Open `index.html` locally to preview it. It is intended to be published as a GitHub Pages user site at <https://jsyzlbw.github.io/>.

## Update

Edit `index.html` for text and links, `styles.css` for appearance, and `portrait.jpg` for the photo. Changes pushed to the `main` branch deploy through GitHub Pages.
